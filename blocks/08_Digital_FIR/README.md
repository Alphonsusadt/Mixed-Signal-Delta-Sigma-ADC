# Block 8 - CIC droop-compensation FIR

Status of every number here: `SIMULATED_NOT_FINAL_PASS` (RTL simulation and a model; not yet run on the FPGA).

## Place in the chain

```
modulator bitstream (1 bit, 4 MHz) -> cic3, sinc^3 R=80 (Block 7) -> fir_comp (this block) -> 21-bit samples, 50 kHz
```

The sinc^3 CIC attenuates the upper part of the signal band: -2.8 dB at the 12.7 kHz test tone,
-7.3 dB at 20 kHz, -11.8 dB at 25 kHz. `fir_comp` flattens the response of CIC x FIR up to 15 kHz.

## Design

| Item | Value |
|---|---|
| Type | linear-phase type-I FIR, 21 taps, least squares (`scipy.signal.firls`) towards 1/H_cic(f) on 0-15 kHz; gain allowed to fall back to 1 towards 25 kHz (low weight) so the shaped quantisation noise at the band edge is not boosted |
| Coefficients | signed 18-bit, 16 fractional bits (fits the Gowin 18x18 multiplier); centre tap adjusted so the taps sum to 2^16 (DC gain exactly 1) |
| Arithmetic | y[n] = (sum c[k] x[n-k] + 2^15) >>> 16, 38-bit accumulator, 21-bit output; no wrap-around possible (worst case checked) |
| Architecture | one multiplier, one tap per clock (serial MAC); output 22 clocks after the input; inputs must be at least 23 clocks apart (540 clocks are available at 50 kHz with a 27 MHz clock); a too-early input is dropped and flags `overrun` |
| Coefficient file | `rtl/fir_coefs.vh`, generated by `python/fir_ref.py` |

## Results

| Check | Result |
|---|---|
| CIC x FIR, 0-15 kHz (fixed-point taps) | -0.115 / +0.028 dB |
| FIR maximum gain / gain at 25 kHz | +3.98 dB / +0.19 dB |
| CIC x FIR at the 12.7 kHz test tone | 0.9994 (CIC alone 0.7224) |
| f6 tone amplitude, CIC only / CIC + FIR | 0.3613 / 0.4998 FS (expected 0.3612 / 0.4997; sine fit on 47 / 26 points, illustrative only, NOT an SNDR) |
| Bit-exact model vs integer convolution | equal (375 samples) |
| RTL vs model (Icarus): impulse, +-full-scale steps, worst-case sign patterns, 200 random samples, f6 CIC output | 375/375 equal at input spacing 23, 24 and 540 clocks; overrun test passes |
| Mutation: output width 20 bits | fails as expected |
| Mutation: centre tap +1 LSB | fails as expected (310 mismatches) |
| Yosys `synth_gowin` estimate (not P&R) | 1 MULT18X18, ~526 LUT, 83 ALU, 501 FF (most FF are the 21 x 20-bit sample history) |

## Limits

- Compensated band 0-15 kHz. Above 15 kHz the response follows the CIC droop again (by design, to avoid boosting noise).
- Only RTL simulation so far. Integration with `cic3` and the replayed bitstream on the Tang Nano 20K is Step 6.
