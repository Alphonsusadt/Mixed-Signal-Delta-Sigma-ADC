# Closed-loop Delta-Sigma modulator (SKY130): transistor-level runs driven from Python

Closes the loop around the six analog blocks and measures the modulator from its bitstream. Python builds the ngspice deck from the block netlists, runs it, and computes SNDR with a coherent-sine FFT.

**Status: `SIMULATED_NOT_FINAL_PASS`.** Transistor-level ngspice runs, TT corner, 1.8 V, 27 C, pre-layout, ideal bias sources, no transient noise. Not a PVT, Monte Carlo or post-layout result.

## Results (transistor level, 300 mV differential sine, OSR 80)

4096-point FFT over a 4112-cycle run (16 warm-up cycles discarded), coherent bin 13, clock period 250 ns (4 MHz), reset 5 us.

| Run (directory under `results/closed_loop/`) | Clock phases | Comparator clock | SNDR @ OSR 80 | ENOB |
|---|---|---|---|---|
| `sine300_n4096` | ideal | ideal | 75.37 dB | 12.23 |
| `f1_sine300_b6_n4096` | generated by Block 6 (NONOV) | ideal | 73.87 dB | 11.98 |
| `f5_sine300_n2_n4096` | generated by Block 6 (NONOV) | from phi2b through 2 inverters | 72.44 dB | 11.74 |

The behavioral model (same loop equations, ideal components) predicts 77.16 dB for this configuration.

How to read it:
- Order-2 noise shaping is preserved in all three runs.
- The 1-3 dB differences between rows are at the level of single-run statistical scatter (about +-1 dB at OSR 80), so they are reported but **not** claimed as a real degradation or as "no degradation". Telling them apart needs reruns at other bins or phases.
- The three bitstreams diverge from the first samples, so a bit-by-bit comparison is meaningless; only spectra are compared.
- Small runs (`smoke4`, `f1_dc100_b6`, `f5_dc100_n2`) check that the loop is alive and that the mean DAC output follows a 100 mV DC input; `sine300_n1024` is a shorter sine run (about 1000 bits).

## Architecture

- Two switched-capacitor integrators (`spice/stage1_core.spice`, `spice/stage2_core.spice`) built from the OTA, SC-CMFB and switch-network blocks.
- StrongARM comparator, two buffers, SR latch, then the 1-bit DAC (`spice/blocks_quantizer_dac.spice`).
- DAC feedback sampling branch `spice/fb_sampler.spice` attached to the summing nodes of each stage (Cd = 1 pF, same LVT transmission gates as Block 5).
- Clock phases either ideal sources or the Block 6 generator (`spice/b6_nonov.spice`, extracted from the Block 6 testbench netlist by `tools/extract_b6_subckts.py`, subcircuits unchanged).
- References: VREFP 1.2 V, VREFN 0.6 V, common mode 0.9 V. Sampling ratios a = Cs/Cf = 0.5 and b = Cd/Cf = 0.5.
- Feedback polarity: stage 2 must use the swapped DAC sampling branch (`--fb2 swap`, the default). The straight option gives positive feedback and the second integrator sticks at a rail (seen in an early smoke run).

| `run_closed_loop_f1.py` | Same driver plus `--phi-source block6` and `--clk-source phi2b-chain --clk-chain N`. |

## Reproducing

Needs ngspice and the SKY130A PDK (path set with `--pdk-lib`). From this directory:

```
python3 run_closed_loop_f1.py --check        # static deck/netlist check, no ngspice
python3 run_closed_loop_f1.py --selftest     # parser -> bitstream -> SNDR path on a synthetic waveform

# ideal phases (baseline), then Block 6 phases, then Block 6 phases plus derived comparator clock
python3 run_closed_loop_f1.py --run --name sine300_n4096 --cycles 4112 --reset-us 5 --amp-mv 300 --bin 13 --osr 80 --model
python3 run_closed_loop_f1.py --run --name f1_sine300_b6_n4096 --phi-source block6 --cycles 4112 --reset-us 5 --amp-mv 300 --bin 13 --osr 80 --model
python3 run_closed_loop_f1.py --run --name f5_sine300_n2_n4096 --phi-source block6 --clk-source phi2b-chain --clk-chain 2 --cycles 4112 --reset-us 5 --amp-mv 300 --bin 13 --osr 80 --model

python3 run_closed_loop_f1.py --analyze results/closed_loop/<run>/waveform.dat --amp-mv 300 --cycles 4112 --osr 80
```

Each 4112-cycle transistor-level run takes several hours. The analysis needs exactly 4096 samples of the bitstream (the files hold 4097 lines).

## Known limits

- Single amplitude (-6 dBFS), single bin, one run per configuration; no transient noise.
- Bias voltages (OTA bias, Block 6 VBN/VBP) are ideal sources. Block 6 at fixed bias is not PVT-robust (see the Block 6 report), so these runs are only meaningful at the nominal point.
- The OTA in the loop differs from the one characterized in Block 1 (Cc 264.5 fF here vs 211.6 fF there, different bias); Block 1 numbers do not transfer automatically.
- The system target was revised to about 75 dB at OSR 80: an ideal 2nd-order 1-bit modulator cannot reach 99 dB there.
- The comparator clock chain (N = 2, 0.46 ns) is not a designed delay; placing the comparator timing deliberately is future work.
- The reset duration is a default, not a validated design requirement.
